# Agent Guidance

This is a React-specific UI package that provides framework integration for
reusable UI elements.

- Keep reusable presentation concerns here; keep application-specific behavior
  in app packages.
- Reuse the base UI package where applicable instead of coupling base elements
  to React.
- Use the root [agent guidance](../../AGENTS.md) for repository-wide principles.
- Use the README for installation, public API, and consumer usage. Read
  `DEVELOPMENT.md` when it exists for maintenance guidance; otherwise inspect
  the workspace structure and scripts.
