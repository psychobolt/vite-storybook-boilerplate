# Storybook Guidance

Use this reference for general Storybook package setup, API usage, and
framework integration. Check the package's Storybook version and target
framework before applying an upstream example.

## Official documentation

- [Storybook API reference](https://storybook.js.org/docs/api)
- [Getting started with frameworks](https://storybook.js.org/docs/get-started/frameworks/)

For repository-specific preview, addon, renderer, and build conventions, read
the relevant `commons` documentation and implementation. For CSF and variant
story conventions, read the [CSF guidance](csf.md).
