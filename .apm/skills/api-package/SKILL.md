# API Package

Placeholder for the future API-package scaffolding workflow.

## Procedure

1. **Apply shared package procedure.** Follow the root [shared package
   procedure](../../../AGENTS.md#shared-package-procedure) before creating files.
2. **Define API-package scope.** API packages will contain reusable
   business-logic utilities, domain services, and API or integration contracts
   when reuse is intentional. Before implementing this skill, define the
   repository's API-package architecture, dependency and boundary rules,
   runtime contracts, environment handling, and validation procedure.
3. **Stop on an unspecified contract.** Until then, read the nearest `AGENTS.md`
   and stop for clarification when the
   package's domain boundary or public API is unspecified.

## Completion checklist

- The shared package procedure is followed before implementation.
- The API-package boundary, runtime, and public API are established or
  clarification is requested.
- API-specific architecture and validation conventions are defined before this
  placeholder workflow is expanded.
