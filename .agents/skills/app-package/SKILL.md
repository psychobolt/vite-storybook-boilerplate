Placeholder for the future application-package scaffolding workflow.

## Procedure

1. **Apply shared package procedure.** Follow the root [shared package
   procedure](../../AGENTS.md#shared-package-procedure) before creating files.
2. **Define app-package scope.** Read the [app-package routing
   guidance](references/routing.md). Application packages will contain
   application composition, screens, workflows, and application-specific
   behavior. Before implementing this skill, define the repository's
   app-package architecture, reference workspaces, build and runtime
   contracts, environment handling, and validation procedure.
3. **Stop on an unspecified contract.** Until then, read the nearest `AGENTS.md`
   and stop for clarification when the
   package boundary or application runtime is unspecified.

## Completion checklist

- The shared package procedure is followed before implementation.

- App-specific architecture and validation conventions are defined before this
